# Luxe E-Commerce App 📱✨

A high-performance, premium E-Commerce mobile experience built with **React Native** and **Expo SDK 55**. Features a modern "Premium Dark" aesthetic with fluid animations and a polished user journey.

---

> [!IMPORTANT]
> This project has been updated with a full **UI Redesign**. Now featuring a sleek "Premium Dark" theme for a more sophisticated shopping experience.

---

## 💎 Premium Features

*   **🔐 Seamless Auth**: Elegant Login/Signup flows with modern input validation. (Functionality Intact)
*   **🏠 Luxe Dashboard**: Dynamic banners and curated categories for high-end discovery.
*   **🔍 Advanced Search**: Real-time product filtering with a sleek, rounded search interface.
*   **📄 Immersive Details**: High-impact product views with integrated wishlist and reviews.
*   **🛒 Smooth Cart**: Intuitive quantity management and detailed pricing summary.
*   **👤 Minimalist Profile**: Clean account management with structured navigation.
*   **⚡ Native Performance**: Built with Reanimated and Native Stack for maximum fluidity.

## 🛠️ Tech Stack & Architecture

| Component | Technology |
| :--- | :--- |
| **Framework** | [Expo](https://expo.dev/) (SDK 55) |
| **Core** | [React Native](https://reactnative.dev/) |
| **Styling** | [StyleSheet](https://reactnative.dev/docs/stylesheet) (Vanilla) |
| **Theme** | Custom "Premium Dark" Color Palette |
| **Navigation** | [React Navigation v7](https://reactnavigation.org/) |
| **Animations** | [Reanimated v4](https://docs.swmansion.com/react-native-reanimated/) |
| **Icons** | [Expo Vector Icons](https://docs.expo.dev/guides/icons/) (Ionicons) |

## 📁 Project Structure

```bash
src/
├── components/     # UI Building Blocks (Header, ProductCard, CartItem)
├── data/           # Product and Category Mock Data
├── navigation/     # App Routing & Tab Configuration
├── screens/        # Full-page View Components
├── types/          # Global TypeScript Definitions
└── utils/          # Universal Constants (New Theme defined here)
```

## 🚀 Getting Started

### 1. Installation
```bash
# Clone the repository
git clone https://github.com/sky-blue-git/Ecom-Mobile-App.git

# Install dependencies
npm install
```

### 2. Execution
```bash
# Start the development server
npx expo start
```

*   **📱 Mobile**: Scan the QR code using **Expo Go**.
*   **💻 Browser**: Press `w` in titles to open in web.
